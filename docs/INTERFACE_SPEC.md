## 1. Shared conventions
- Keys are `bytes`, always 32 bytes. Passphrases are `str`. Paths are `pathlib.Path`.
- `file_id`: `str`, random, e.g. `"F-" + 8 hex chars`. Generated by `add-file`, never derived from the filename.
- `child_id`: `str`, e.g. `"CH-4F7A"`.
- Time: UTC ISO-8601 string with `Z` suffix, e.g. `"2026-03-02T10:15:00Z"` (one helper `now_utc()` in `errors.py`/`util.py`).
- Roles: exactly `"owner" | "researcher" | "reviewer"`.
- Actions (audit/permissions): `add_file, open_file, pseudonymize, lookup, share, import_bundle, revoke, verify, audit_show, login`.
- Fail loudly: tampering = exception, never a silent `False`.

## 2. Exceptions (errors.py)
    class VaultError(Exception)
    class IntegrityError(VaultError)      # GCM tag failure, bad chunk order, truncation, log chain broken
    class AuthError(VaultError)           # wrong passphrase / key unwrap failed
    class PermissionDenied(VaultError)    # role not allowed
    class BundleError(VaultError)         # bad signature, expired, wrong recipient, file not in scope

## 3. Keys – crypto/keys.py (Aaleen)
    new_salt() -> bytes                                   # 16 random bytes
    derive_kek(passphrase: str, salt: bytes) -> bytes     # scrypt -> 32 bytes
    new_data_key() -> bytes                               # 32 random bytes
    wrap_key(kek: bytes, data_key: bytes) -> bytes        # nonce || AESGCM(kek).encrypt(...)
    unwrap_key(kek: bytes, wrapped: bytes) -> bytes       # raises AuthError

## 4. File encryption – crypto/files.py (Aaleen)
    encrypt_file(src: Path, dst: Path, data_key: bytes, file_id: str) -> None
    decrypt_file(src: Path, dst: Path, data_key: bytes, file_id: str) -> None   # raises IntegrityError
    CHUNK_SIZE = 1_048_576
**Format (needs Aaleen's confirmation):** header = magic `CVLT` + version byte + base nonce prefix + chunk count;
each chunk = AES-256-GCM, nonce = prefix || chunk_index, **AAD = file_id || chunk_index || is_last_flag**.
The `is_last` flag and the chunk count in the header are what make truncation detectable, and the chunk
index in AAD is what makes chunk swaps detectable. Empty file (0 bytes) must round-trip.

## 5. Database – db.py (Mariyam)
    connect(vault_dir: Path) -> sqlite3.Connection
    init_schema(conn) -> None
Tables (minimum): `files(file_id, child_id, original_name_enc, enc_path, wrapped_key, created_at, owner)`,
`audit_log(seq, ts, actor, action, file_id, prev_hash, entry_hash)`, `users(username, role, x25519_pub, ed25519_pub)`,
`meta(key, value)` (salt, HMAC-signed head hash).

## 6. Pseudonymization – pseudonym.py (Mariyam)
    pseudonymize(name: str) -> str                 # returns child_id; same name -> same id
    lookup(child_id: str, kek: bytes) -> str       # owner only; returns real name
    Map is stored as one encrypted file, separate from file records.

## 7. Audit log – audit.py (Laiba)
    append_event(conn, actor: str, action: str, file_id: str | None, hmac_key: bytes) -> str   # returns entry_hash
    verify_chain(conn, hmac_key: bytes) -> VerifyResult      # VerifyResult(ok: bool, broken_at: int | None, reason: str)
    show(conn, limit: int | None = None) -> list[dict]
entry_hash = SHA-256( seq | ts | actor | action | file_id | prev_hash ), first entry's prev_hash = 32 zero bytes.
After every append, head hash is HMAC-signed (key derived from KEK) and stored in `meta`.
That HMAC is what catches deletion of the *last* entries, which a bare chain cannot detect.
Every other module calls `append_event` – nobody writes to `audit_log` directly.

## 8. Permissions – access.py (Laiba)
    require(role: str, action: str) -> None        # raises PermissionDenied
| action | owner | researcher | reviewer |
|---|---|---|---|
| add_file, pseudonymize, share, revoke | yes | add_file only | no |
| open_file | yes | yes | only files in an imported valid bundle |
| lookup (real name) | yes | no | no |
| audit_show, verify | yes | verify only | no |
| import_bundle | no | no | yes |
(Draft – confirm with team.) Denied attempts are also logged (`action="denied:<action>"`).

## 9. Sharing – sharing.py (Aaleen signs, Mariyam wraps)
    create_bundle(owner_ed_priv, reviewer_x_pub, file_ids: list[str], expires_at: str, keys: dict[str, bytes]) -> bytes
    open_bundle(bundle: bytes, reviewer_x_priv, owner_ed_pub, now: str) -> dict[str, bytes]   # file_id -> data_key
Raises `BundleError` on: bad signature, `now > expires_at`, wrong reviewer key. A file not in the bundle is not returned.
`now` is a parameter (not read inside) so Laiba's expiry tests can fake time.

## 10. CLI contract (cli.py, Mariyam owns the skeleton)
    vault init | add-file | open-file | pseudonymize | lookup | audit show | verify | share | import-bundle | revoke
Each command: check role (`require`) -> do work -> `append_event` -> print result. Exit code 1 on any VaultError.

## 11. Test conventions (Laiba)
- Use fixtures from `tests/conftest.py`: `synthetic_dir` (read-only), `sample_files` (safe copies to tamper), `work_dir`, `passphrase`.
- Attack tests assert a specific exception type, e.g. `with pytest.raises(IntegrityError)`.
- Name: `tests/test_attack_<module>.py`, functions `test_attack_<what>`.
